这是一个在本机运行的 本地行情、仓位与风险。当前基线只提供可编译、可测试的起点。

## 本地模拟交易

`book.Engine` 在 `Ready()` 基线之外提供由调用方驱动的单账户、多合约模拟交易：

```go
e, _ := book.NewEngine(1000)                 // 非负初始现金
e.SetMaxPosition("A", 100)                    // 每个合约须先设置非负最大持仓量
e.UpdateQuote("A", book.Quote{Seq: 1, Moment: 10, Price: 10}) // 序号必须连续

id, _ := e.Buy("A", 10, 10)                   // 买单按限价×数量占用现金
e.Fill(book.Trade{TradeID: 1, OrderID: id, Symbol: "A", Side: book.Buy, Price: 9, Qty: 4}) // 调用方提交成交
e.Cancel(id)                                  // 撤销只释放未成交部分

e.Cash()            // 现金余额
e.AvailableCash()   // 可用现金
e.ReservedCash()    // 占用现金
e.Position("A")     // 持仓数量
e.Sellable("A")     // 可卖数量
e.Records()         // 接受/拒绝/成交/撤销记录（含当时报价与限额快照）
```

规则要点：只允许先买后卖，不借款、不做空；报价跨号时等待补齐、缺口期间拒绝新买单；
成交编号幂等（同编号同内容返回原结果，不同内容报错）；下调持仓限额会从最后接受的
买单起撤销剩余量。详见 `book/engine.go` 的文档注释。

## 日内亏损保护

`book.Engine` 在交易之上提供由调用方驱动的单账户日内亏损保护：

```go
e, _ := book.NewEngine(1000)
e.SetMaxPosition("A", 100)
e.UpdateQuote("A", book.Quote{Seq: 1, Moment: 10, Price: 10})

e.StartDay(1, 100)   // 以正整数日号和非负亏损上限开始交易日
rs := e.RiskStatus() // 查询日号、基准/当前净值、亏损、上限、是否已限制
e.SetLimit(50)       // 当日调整上限（未开日时报错）
```

规则要点：

- 日号由调用方明确发起，不从行情时刻推导；同日号同上限重复开日不产生变化，
  同日号不同上限、倒退日号、非正日号或负上限均报错且不改状态。
- 开日基准净值 = 现金余额 + 各合约持仓按最新已生效报价计算的市值（订单占用不重复扣除）；
  日内亏损 = 基准净值 − 当前净值，盈利时记零。
- 亏损达到或超过上限时立即限制增险：拒绝所有新买单，按订单编号从大到小撤销全部有效
  买单的未成交部分并释放占用；已入账成交与持仓保留；卖单及其成交、主动撤单仍按原规则处理。
- 零上限开日即触线；限制持续到下一交易日，报价回升、卖出盈利或调高上限均不解除。
- 每条真正生效的报价与每笔首次成功入账的成交都重新计算风险；跨号等待的报价不参与估值，
  补齐后逐条生效，中间价格触线、最后价格恢复仍保留限制。
- 触线记录注明引发方式（开日/调限额/报价/成交）、关联报价序号或成交编号，并保存
  各持仓合约的报价序号、时刻与价格快照；触线造成的拒绝与撤销记录保留当日亏损与上限。
- 启用期间若净值或亏损超出 int64 范围，对应开日、调限额、报价或成交整体报错，
  除拒绝记录外不改变任何业务状态。
